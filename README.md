# kiro-test

Un "Hola Mundo" molón 🚀 hecho con HTML, CSS y JavaScript.

## ¿Qué incluye?

- Fondo animado con blobs y gradientes de colores.
- Título con animación de entrada y texto con efecto de brillo (shine).
- Botón interactivo que lanza confeti de emojis 🎉.
- Diseño responsive.

## Cómo verlo

Abre `index.html` en tu navegador. ¡Eso es todo!

## Archivos

- `index.html` — estructura de la página.
- `styles.css` — estilos y animaciones.
- `script.js` — interactividad (el confeti).
